# 桌面宠物 Desktop Pet

一个可爱的桌面宠物应用，使用 Electron 开发，支持 Windows 和 macOS。

## 功能特性

### 🎮 基础互动功能
- ✅ 宠物行为动画：待机、跳跃、吃东西等
- ✅ 拖拽与点击互动：可拖动宠物，点击有反应
- ✅ 定时提醒：喝水、休息提醒
- ✅ 情绪系统：根据饥饿度和精力值变化情绪

### 🧩 扩展功能
- ✅ 定时提醒系统：喝水、休息、站立、运动提醒
- ✅ 天气同步：宠物根据天气变化做出反应
- ✅ 多种宠物类型：猫、狗、兔子、羊、猫头鹰
- 🔄 换装系统
- 🔄 成长机制
- 🔄 小游戏
- 🔄 语音互动

## 安装和运行

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装依赖
```bash
npm install
```

### 开发模式运行
```bash
npm run dev
```

### 打包应用
```bash
npm run build
```

## 使用说明

1. **基础互动**
   - 点击宠物：播放开心动画
   - 拖拽宠物：移动到屏幕任意位置
   - 右键菜单：喂食、玩耍、睡觉等操作

2. **宠物状态**
   - 饥饿度：随时间增加，喂食可降低
   - 精力值：随时间减少，睡觉可恢复
   - 情绪：根据饥饿度和精力值自动变化

3. **定时提醒**
   - 💧 喝水提醒（每2小时）
   - 👀 休息提醒（每1小时）
   - 🚶‍♂️ 站立提醒（每45分钟）
   - 🏃‍♂️ 运动提醒（每3小时，可选）
   - 支持延迟和关闭提醒

4. **天气同步**
   - 🌧️ 下雨时显示雨滴效果
   - ☀️ 晴天时显示阳光效果
   - ❄️ 下雪时显示雪花效果
   - 宠物根据天气调整心情和行为

## 新功能使用说明

### 定时提醒
1. 在设置中可以开启/关闭各种提醒
2. 提醒弹窗支持"知道了"和"稍后提醒"
3. 稍后提醒会在10分钟后再次弹出
4. 宠物会配合提醒做相应动画

### 天气同步
1. 在设置中开启"启用天气同步"
2. 可以设置城市名称
3. 右键菜单选择"天气"查看当前天气
4. 宠物会根据天气显示不同效果和心情

### 宠物类型
- 🐱 猫咪：独立、爱睡觉、会理毛
- 🐶 狗狗：活泼、爱玩、会摇尾巴
- 🐰 兔子：温和、耳朵敏感、会跳跃
- 🐑 小羊：温和、毛茸茸、会咩咩叫
- 🦉 猫头鹰：神秘、大眼睛、会转头
