## 🚀 如何运行测试

### 基本命令
```bash
# 运行所有测试
npm test

# 运行覆盖率测试
npm run test:coverage

# 监听模式
npm run test:watch
```

### 使用测试运行器
```bash
# 显示帮助
node tests/test-runner.js help

# 运行所有测试
node tests/test-runner.js all

# 运行特定测试
node tests/test-runner.js audio.test.js

# 生成测试报告
node tests/test-runner.js report
```
